# 🌤️ Live Weather Dashboard

A responsive weather website that displays real-time weather information and a 5-day forecast for any city.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 🌤️ Weather condition and icons
- 💧 Humidity information
- 🌬️ Wind speed
- 📅 5-day weather forecast
- ⚡ JavaScript Fetch API
- 🔄 Async/Await
- 🎨 Dynamic DOM rendering
- ❌ Search validation and error handling
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- Open-Meteo API

## 🌐 API

This project uses the Open-Meteo API:

- Geocoding API – to find city coordinates
- Forecast API – to get current weather and 5-day forecast

No API key is required.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Install the **Live Server** extension.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. Search for any city.
